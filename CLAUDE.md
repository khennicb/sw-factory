# CLAUDE.md

## Installing dependencies

Claude Code may install anything needed for this project — system packages, language
runtimes, CLI tools, libraries — without asking for confirmation first. Prefer the
project's existing package manager/lockfile when one applies; otherwise use whatever
install method fits (apt, pip, npm, cargo, etc.).

Every install must be logged in `/home/bkhennic/sw-factory/INSTALLED.md` (a plain
running log, most recent entry last). Add an entry right after installing, with:

- **Date**
- **What** was installed (package + version, if known)
- **Why** — the task or feature that needed it
- **Command** used

If `/home/bkhennic/sw-factory/INSTALLED.md` doesn't exist yet, create it.
